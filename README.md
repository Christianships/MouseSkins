<h1 align="center">MouseSkins</h1>

<p align="center">Custom mouse cursors for your whole Mac.</p>

## Install

Needs macOS 13+ with the Xcode command line tools (`xcode-select --install`).

1. Download and unzip this repo.
2. In the folder, run `./build.sh`. It installs MouseSkins to `~/Applications` and opens it.

## Use

- **Home:** double-click a skin to apply it.
- **Skins:** browse about 50 free skins and install one in a click.
- **Edit:** adjust the selected skin's cursors.
- **Settings:** open at login, cursor size, left-handed mode, and swing on click (sword skins swing like in Minecraft).

The cursor icon in the menu bar opens the panel again. To go back to the
normal macOS cursors, run `~/.local/bin/mouseskins reset`.
